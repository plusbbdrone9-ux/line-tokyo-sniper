# 🎯 LINE Personal Auto-CF Sniper Bot (PC Desktop Edition)

โปรแกรม Desktop สำหรับระบบปฏิบัติการ Windows ที่นำ **LINE ส่วนบุคคล (Personal Account)** เข้าไปเฝ้าดูและแย่งพิมพ์ **"CF" (Confirm / จองสินค้า)** ใน **กลุ่มไลน์, LINE OpenChat และ LINE OA** โดยอัตโนมัติด้วยความเร็วระดับเสี้ยววินาที (**100 - 250 มิลลิวินาที**)

---

## 🌟 หน้าจอโปรแกรมบน Windows (Desktop GUI Features)

พัฒนาด้วย **CustomTkinter** ดีไซน์ Dark Mode ทันสมัย สวยงามแบบ Windows 11 Fluent Design:

1. **สวิตช์เปิด-ปิดฉุกเฉิน (Master Sniper Switch):**
   - ปุ่มใหญ่ด้านบนสีเขียว 🟢 เปิดสไนเปอร์ / สีแดง 🔴 หยุดสไนเปอร์ฉุกเฉินในคลิกเดียว
2. **ตัวตรวจจับหน้าต่าง LINE PC อัตโนมัติ:**
   - กดปุ่ม **"🔄 ค้นหาหน้าต่าง LINE"** โปรแกรมจะค้นหาหน้าต่างแชทของ LINE PC ที่กำลังเปิดอยู่ให้เลือกทันที
3. **แท็บ 1: 🎯 เรดาร์ & ทดสอบยิง CF (Radar & Simulator):**
   - **Simulator:** วางข้อความโพสต์ขายของของแม่ค้า แล้วกด **"🎯 ทดสอบประเมินเงื่อนไข"** หรือกด **"⚡ ยิง CF จริงเข้า LINE PC!"** ได้ทันที
   - **Live Radar Log:** หน้าต่างแสดงประวัติข้อความและผลการตรวจจับแบบ Real-time
4. **แท็บ 2: 📜 จัดการกฎการ CF (Rules Manager):**
   - เพิ่ม/ลบ กฎการ CF สินค้าแต่ละกลุ่มได้อิสระ
   - กำหนด Target Keywords, คำต้องห้าม (Negative), รูปแบบข้อความ (`CF {code} พร้อมโอน`), และเพดานราคาสูงสุด
   - มีสวิตช์เปิด-ปิดการทำงานของแต่ละกฎแยกกัน
5. **แท็บ 3: 🏆 ประวัติการ CF สำเร็จ (Sniper Wins Log):**
   - แสดงประวัติรายการที่บอทยิง CF สำเร็จ พร้อมเวลา, ชื่อกลุ่ม, ข้อความแม่ค้า, และความเร็ว (ms)
6. **แท็บ 4: ⚙️ ตั้งค่าความเร็ว & ป้องกันแบน (Settings):**
   - แถบปรับหน่วงเวลาจำลองการพิมพ์ (Jitter Delay) เช่น 150 - 300 ms เพื่อดูเป็นธรรมชาติและป้องกันการโดนเตะออกจาก OpenChat

## 💡 ขั้นตอนการใช้งานร่วมกับ LINE PC

1. เปิดแอปพลิเคชัน **LINE บนคอมพิวเตอร์ Windows** และเข้าสู่ระบบด้วยบัญชีส่วนตัวของคุณ
2. ดับเบิ้ลคลิกเปิดหน้าต่างแชทของ **กลุ่ม หรือ OpenChat** ที่ต้องการสไนเปอร์ซื้อของ
3. เปิดโปรแกรม **[`Start_LINE_CF_Sniper.bat`](file:///e:/project_ai/chat-line-bot/Start_LINE_CF_Sniper.bat)**
4. กดปุ่ม **"🔄 ค้นหาหน้าต่าง LINE"** ที่มุมขวาบนของโปรแกรม แล้วเลือกหน้าต่างแชทนั้น
5. ตั้งกฎคีย์เวิร์ดสินค้าที่ต้องการในแท็บ **"📜 จัดการกฎการ CF"** (มีตัวอย่าง Labubu และรหัสสินค้าทั่วไปตั้งไว้ให้แล้ว)
6. เมื่อแม่ค้าโพสต์ข้อความลงในกลุ่ม บอทจะตรวจจับคีย์เวิร์ด สกัดรหัสสินค้า โฟกัสหน้าต่าง พิมพ์ และกดส่งข้อความ CF ในทันที!
